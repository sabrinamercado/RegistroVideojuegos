## Requisitos

- Tener instalado el SDK de .NET 11 o una versión compatible con el proyecto.
- Tener acceso a internet durante la restauración inicial del paquete NuGet.

## Instrucciones de ejecución

1. Clonar el repositorio:

   `git clone https://github.com/sabrinamercado/RegistroVideojuegos.git`

2. Entrar en la carpeta:

   `cd RegistroVideojuegos`

3. Restaurar las dependencias:

   `dotnet restore`

4. Ejecutar el programa:

   `dotnet run`

La base de datos se creará automáticamente cuando se ejecute la aplicación.
